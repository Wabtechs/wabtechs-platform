# Roadmap — Wabtechs Platform

## MVP (MVP 1.0)

- SSO centralisé (OIDC) + gestion des sessions
- Annuaire et gestion des utilisateurs
- RBAC et permissions
- Gestion des licences et abonnements
- Billing et facturation
- API Gateway et clés API
- Notifications centralisées
- Monitoring et tableaux de bord

## Versions futures

- Marketplace de modules
- IA : assistance, recommandations, anomalies
- Pilotage multi-produits (usage, SLA)
- Portail client et self-service
- Observabilité avancée (OpenTelemetry)
